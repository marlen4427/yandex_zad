# yandex_zad
1. Задание
https://coderun.yandex.ru/problem/median-out-of-three
Способ 1 (Сортировка): Числа помещаются в список. Метод sort() упорядочивает их по возрастанию. После этого средний элемент гарантированно находится под индексом 1 (второй по счету). Используется структура данных список (list). Встроенная сортировка в Python написана на C и работает очень быстро. 

Способ 2 (Математика): Если сложить все три числа, а затем вычесть из полученной суммы самое маленькое (min) и самое большое (max) число, останется ровно то число, которое является средним. Не использует дополнительных структур данных (работает только с переменными) и опирается на встроенные функции min и max, что делает его самым быстрым по времени выполнения.

Способ 3 (Условия): Перебираются все возможные варианты расположения чисел. Конструкция вида a <= b <= c в Python проверяет, что b находится между a и c (или равно им). Не требует дополнительной памяти или встроенных функций и подошел бы для любого языка программирования.
